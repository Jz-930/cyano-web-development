## F-01 手机首屏说明条压在样机上（阶段 0）

**原因**：`.hero-bottom` 在 `v3-foundation.css` 中是 `position:absolute;bottom:31px`，手机上首屏改成纵向排列后，它仍然绝对定位在首屏底部，正好压在样机底部的“15 分钟”和“View full screen”上。

**步骤**

1. 打开 `site/components/v3/pages/Home.tsx`，删除下面这一段（装饰性英文坐标，不属于 v1 文案）：

```tsx
          <div className="visual-coordinate">
            
            CYANO / ENTERPRISE AI
          </div>
```

2. 打开 `site/app/styles/v3.css`，在文件**末尾**追加一行（阶段 1 格式化时会被归入正确位置）：

```css
@media (max-width:800px){.home-hero .hero-bottom{position:static;inset:auto;margin:32px 0 0;width:auto;padding:0;gap:16px;flex-wrap:wrap}}
```

3. 同一文件末尾再追加（删除已无元素使用的样式引用不是必须，但避免残留）：

```css
.visual-coordinate{display:none!important}
```

> 这一条带 `!important` 是临时的，阶段 1 第 2.4 步会删掉 `.visual-coordinate` 的全部规则（包括这一条）。

**验收**

- 390×844 打开 `/` 与 `/en`：说明条出现在样机**下方**，与样机之间至少 24px 空隙，不覆盖任何文字。
- 在浏览器控制台执行下面代码，输出 `false`：

```js
const a=document.querySelector('.hero-bottom').getBoundingClientRect(),b=document.querySelector('.hero-stage-wrap').getBoundingClientRect();a.top<b.bottom&&a.bottom>b.top
```

### 2. 表单改为自定义校验

**文件**：`site/components/v3/ContactFormClient.tsx`

1. `<form>` 加属性 `noValidate`。
2. 文件顶部、组件外加校验函数：

```tsx
type FieldError = { name: string; message: string };
function validate(form: HTMLFormElement, locale: Locale): FieldError[] {
  const errors: FieldError[] = [];
  const zh = locale === "zh";
  for (const el of Array.from(form.elements) as (HTMLInputElement|HTMLSelectElement|HTMLTextAreaElement)[]) {
    if (!el.name || el.disabled) continue;
    if (el.type === "checkbox") {
      if ((el as HTMLInputElement).required && !(el as HTMLInputElement).checked)
        errors.push({ name: el.name, message: zh ? "请先阅读并同意隐私政策。" : "Please accept the Privacy Policy to continue." });
      continue;
    }
    const v = el.value.trim();
    if (el.required && !v) { errors.push({ name: el.name, message: zh ? "请填写这一项。" : "Please fill in this field." }); continue; }
    if (el.type === "email" && v && !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(v))
      errors.push({ name: el.name, message: zh ? "请填写有效的邮箱地址。" : "Please enter a valid email address." });
  }
  return errors;
}
```

3. 组件内加状态 `const [fieldErrors, setFieldErrors] = useState<Record<string,string>>({});`
4. `submit` 函数第一行 `e.preventDefault();` 之后插入：

```tsx
    const errs = validate(e.currentTarget, locale);
    if (errs.length) {
      setFieldErrors(Object.fromEntries(errs.map(x => [x.name, x.message])));
      const first = e.currentTarget.elements.namedItem(errs[0].name) as HTMLElement | null;
      first?.focus();
      return;
    }
    setFieldErrors({});
```

5. 每个字段渲染时加（以 `name="email"` 为例，所有字段同样处理）：

```tsx
<input name="email" type="email" required
  aria-invalid={fieldErrors.email ? true : undefined}
  aria-describedby={fieldErrors.email ? "err-email" : undefined}
  onInput={() => fieldErrors.email && setFieldErrors(({email, ...rest}) => rest)} />
{fieldErrors.email && <p id="err-email" className="field-error">{fieldErrors.email}</p>}
```

6. 错误提示的 4 句文字是甲类文字，已登记在 `09` 文件 §1。
