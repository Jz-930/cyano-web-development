# v4 实施手册 · 04 动效 Token 与微交互规范（阶段 2）

> 目标：全站 0 个 0ms 的状态切换；每个可交互元素都有悬停或按下反馈；键盘焦点清楚可见；减弱动效时只保留颜色与透明度变化。
> 本文件的 CSS 写入 `v4/motion.css` 与 `v4/components/*.css`（文件名见每节标题），客户端逻辑写入 `site/components/v4/`。

---

## 1. `v4/motion.css` 全文

```css
:root{

  --ease-out:cubic-bezier(.2,.7,.2,1);
  --ease-in-out:cubic-bezier(.65,0,.35,1);
  --ease-exit:cubic-bezier(.4,0,1,1);
  --ease-spring:linear(0,.22 7%,.62 17%,.9 28%,1.02 40%,1.01 55%,1);
  --ease:var(--ease-out);
  --lift-1:-2px; --lift-2:-4px;
}
@supports not (transition-timing-function:linear(0,1)){:root{--ease-spring:cubic-bezier(.34,1.3,.64,1)}}
@media (prefers-reduced-motion:reduce){
  :root{--dur-base:1ms;--dur-enter:1ms;--dur-scene:1ms;--dur-story:1ms;--dur-base-out:1ms;--dur-enter-out:1ms;--dur-scene-out:1ms;--lift-1:0px;--lift-2:0px}
  *,*::before,*::after{animation-duration:1ms!important;animation-iteration-count:1!important;scroll-behavior:auto!important}
```

> 这是全站唯一允许写 `!important` 的位置。`--dur-press` 与 `--dur-fast` 在减弱动效下保留（颜色与透明度变化不算运动）。

## 2. 通用规定

1. 过渡只写具体属性，不写 `transition:all`。
2. 进入用 `--ease-out`，退出用 `--ease-exit` 与 `*-out` 时长；场景与描线用 `--ease-in-out`；指示块、FLIP、回弹用 `--ease-spring`。
3. 布局文件 `<head>` 里加一段内联脚本（两个布局都加，放在 `<body>` 之前的 `<head>` 内）：

```tsx
<head><script dangerouslySetInnerHTML={{__html:"document.documentElement.classList.add('js')"}}/></head>
```

所有“初始隐藏、进入后显示”的样式都必须以 `html.js` 开头，禁用 JS 时内容直接可见。
4. 指针设备区分：悬停效果写在 `@media (hover:hover) and (pointer:fine){…}` 里；触屏只有按下态。
5. 焦点样式统一：

```css
:focus-visible{outline:2px solid var(--link);outline-offset:3px;border-radius:inherit}
.dark :focus-visible,[data-surface="dark"] :focus-visible{outline-color:var(--cyan)}
```

（`--cyan` 在纸面上对比度只有 2:1，所以纸面用 `--link`。）

### 3.7 选项卡（`components/tabs.css`，逻辑 `components/v4/useTabs.ts`）

全站所有 `role="tablist"`（首页方案区、首页“四个工程问题”、方案总览筛选等）统一用 `useTabs`：

```ts
"use client";
import { useRef, useState, useCallback } from "react";
export function useTabs(count: number, initial = 0) {
  const [selected, setSelected] = useState(initial);
  const [leaving, setLeaving] = useState<number | null>(null);
  const tabs = useRef<(HTMLButtonElement | null)[]>([]);
  const select = useCallback((i: number) => {
    setSelected(prev => { if (prev !== i) { setLeaving(prev); window.setTimeout(() => setLeaving(null), 154); } return i; });
  }, []);
  const onKeyDown = (e: React.KeyboardEvent, i: number) => {
    const map: Record<string, number> = { ArrowRight: i + 1, ArrowDown: i + 1, ArrowLeft: i - 1, ArrowUp: i - 1, Home: 0, End: count - 1 };
    if (e.key in map) { e.preventDefault(); const n = (map[e.key] + count) % count; tabs.current[n]?.focus(); return; }
    if (e.key === "Enter" || e.key === " ") { e.preventDefault(); select(i); }
  };
  const tabProps = (i: number) => ({
    ref: (el: HTMLButtonElement | null) => { tabs.current[i] = el; },
    role: "tab" as const, "aria-selected": selected === i, tabIndex: selected === i ? 0 : -1,
    onClick: () => select(i), onKeyDown: (e: React.KeyboardEvent) => onKeyDown(e, i),
  });
  const panelProps = (i: number) => ({
    role: "tabpanel" as const, hidden: selected !== i && leaving !== i,
    "data-state": selected === i ? "enter" : leaving === i ? "exit" : "idle",
  });
  return { selected, select, tabProps, panelProps };
}
```

- **焦点与选中分离**：方向键只移动焦点，Enter/空格/点击才选中。删除 `SolutionExplorerClient.tsx` 第 56 行的 `onFocus={() => setSelected(i)}`。
- 未选中的选项卡**允许**用 `tabIndex=-1`，但方向键能移到它们。

```css
[role="tablist"]{position:relative}
[role="tab"]{transition:color var(--dur-fast) var(--ease-out),background-color var(--dur-fast) var(--ease-out)}
@media (hover:hover) and (pointer:fine){[role="tab"][aria-selected="false"]:hover{background:var(--ink-06)}.dark [role="tab"][aria-selected="false"]:hover{background:var(--white-04)}}
.tab-indicator{position:absolute;left:0;width:2px;background:var(--cyan);top:0;height:var(--th,0);transform:translateY(var(--ty,0));transition:transform var(--dur-base) var(--ease-spring),height var(--dur-base) var(--ease-spring)}

[role="tabpanel"][data-state="exit"]{position:absolute;inset:0;animation:panel-out var(--dur-base-out) var(--ease-exit) both;pointer-events:none}
@keyframes panel-in{from{opacity:0;transform:translateY(8px)}to{opacity:1;transform:none}}

```

- 竖排选项卡用 `.tab-indicator` 竖条（左侧 2px），横排选项卡改为底部横条：`.tablist-h .tab-indicator{top:auto;bottom:0;height:2px;width:var(--tw,0);transform:translateX(var(--tx,0))}`。指示条位置由 `useTabs` 调用方在 `selected` 变化后读取当前选项卡的 `offsetTop/offsetHeight`（竖）或 `offsetLeft/offsetWidth`（横）写入 CSS 变量。

## 5. 验收脚本 `site/scripts/check-interactions.mjs`

Playwright（1440×900，`hasTouch:false`），对全部页面：

1. 收集所有可交互元素：`a[href]`、`button`、`[role="tab"]`、`summary`、`input`、`select`、`textarea`、`label:has(input)`，排除不可见元素与跳转链接。
2. 对每个元素记录计算样式：`color`、`background-color`、`border-color`、`box-shadow`、`transform`、`opacity`、`background-size`、`text-decoration-color`，以及它的 `::after`、第一个 `svg` 子元素与最近的 `.card` 祖先的 `transform`、`box-shadow`、`border-color`。
3. `element.hover()` 后等 400ms 再记录一次；`mouse.down()` 后等 120ms 再记录一次。
4. **悬停或按下至少一项有变化**，否则报“无反馈”。
5. 对有变化的属性，读取 `transition-duration`（或对应 `animation-duration`），为 0 的报“0ms 切换”。
6. Tab 键遍历每个页面，每个获得焦点的元素截取外接矩形 +8px 区域，计算焦点环像素与相邻背景的对比度 ≥ 3:1。

输出 `reports/interactions.json`。**“无反馈”与“0ms 切换”都必须为 0 条。**
