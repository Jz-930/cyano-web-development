### 1.2 新的着色器（`light-field.js` 中 `fragment` 常量整体替换）

```glsl
precision mediump float;
uniform vec2 resolution;uniform float time;uniform vec2 pointer;uniform float phase;
uniform float strength;uniform vec2 focus;uniform float mode;uniform float intro;uniform float textEdge;
float hash(vec2 p){return fract(sin(dot(p,vec2(127.1,311.7)))*43758.5453);}
float noise(vec2 p){vec2 i=floor(p),f=fract(p);f=f*f*(3.-2.*f);return mix(mix(hash(i),hash(i+vec2(1.,0.)),f.x),mix(hash(i+vec2(0.,1.)),hash(i+vec2(1.,1.)),f.x),f.y);}
float fbm(vec2 p){return .55*noise(p)+.28*noise(p*2.03)+.17*noise(p*4.01);}
float lineY(float i,float x,float t){
  float spread=(i-1.)*.075;
  if(mode<.5){
    float k=clamp((x-focus.x)/max(1.-focus.x,.001),0.,1.);
    float y=mix(focus.y+spread*.15,.92+spread,pow(k,1.4));
    return y+.012*sin(x*9.+t*.8+i*2.1);
  }
  float k=clamp(x/max(focus.x,.001),0.,1.);
  float y=mix(.5+(i-1.)*.28,focus.y,smoothstep(0.,1.,k));
  return y+.010*sin(x*8.+t*.7+i*1.7)*(1.-k);
}
void main(){
  vec2 uv=gl_FragCoord.xy/resolution;uv+=pointer*.07;
  float t=time*.25+phase;
  vec2 warp=vec2(fbm(uv*3.+t*.15),fbm(uv*3.+vec2(4.3,t*.12)));
  float n=fbm(uv*4.+warp*.8+vec2(t*.08,-t*.1));
  float dir=mode<.5?1.:-1.;
  float band=0.;
  for(int j=0;j<3;j++){
    float i=float(j);
    float d=uv.y-lineY(i,uv.x,t);
    float w=.0016+.0022*abs(uv.x-focus.x);
    float core=exp(-d*d/w);
    float seg=mode<.5?smoothstep(focus.x-.03,focus.x+.02,uv.x):1.-smoothstep(focus.x-.01,focus.x+.04,uv.x);
    float pulse=pow(.5+.5*sin((uv.x*6.+dir*t*.9+i*.37)*6.2831),12.);
    band+=core*seg*(.55+.9*pulse)*(.7+.15*i);
  }
  if(mode>.5){band+=exp(-pow(uv.y-focus.y,2.)/.0012)*smoothstep(focus.x,focus.x+.02,uv.x)*(1.-smoothstep(focus.x,1.,uv.x))*.6;}
  float dist=mode<.5?1.-uv.x:uv.x;
  float front=intro*1.25;
  float reveal=1.-smoothstep(front-.25,front,dist);
  float edge=exp(-pow((dist-front+.1)*14.,2.))*(1.-intro)*.5;
  float textMask=mix(.2,1.,smoothstep(textEdge,textEdge+.14,uv.x));
  vec2 ambC=mode<.5?vec2(.86,.78):focus;
  float amb=exp(-length((uv-ambC)*vec2(1.1,1.5))*3.)*(.3+n*.35);
  float fg=exp(-length((uv-focus)*vec2(1.,1.6))*9.);
  vec3 col=vec3(.027,.043,.059);
  col+=vec3(.015,.13,.16)*amb*strength*textMask*reveal;
  col+=vec3(.07,.52,.62)*band*.5*strength*textMask*reveal;
  col+=vec3(.4,.72,.77)*pow(band*.5,3.)*.2*strength*textMask*reveal;
  col+=vec3(.06,.45,.55)*fg*.6*strength*reveal;
  col+=vec3(.07,.52,.62)*edge*strength*textMask;
  col+=(hash(gl_FragCoord.xy+fract(time)*91.7)-.5)*.028;
  gl_FragColor=vec4(col,1.);
}
```

逐项说明（实现时不要改数值，只核对）：

1. `mode`：`0` = 首屏形态（三条流线从右上进入，汇聚到 `focus`）；`1` = 汇聚形态（三条流线从左侧进入，在 `focus` 汇合后合成一条向右延伸并渐隐）。
2. `focus`：汇聚点，归一化坐标（左下为原点）。由 JS 根据页面元素位置计算（§1.3）。
3. `strength`：整体亮度，0–1。
4. `textEdge`：文字栏右边界（归一化 x）。左侧文字栏内的光线亮度压到 20%。
5. `intro`：0→1，加载时光带扫入（首屏形态从右向左扫，汇聚形态从左向右扫），带一条亮的前沿。
6. 颗粒：`0.028`（原来 `0.018`），每帧变化，单色。
7. 指针：`uv += pointer * 0.07`，`pointer` 在 JS 里做阻尼（§1.3）。
8. 光点：`pulse` 让每条线上有沿流向移动的亮段，首屏形态向左（流向样机），汇聚形态向右。

### 1.3 `mountField` 改动

函数签名改为：

```js
export function mountField(host, { mode = 0, strength = 1, focusEl = null, focus = [0.7, 0.5], textEdgeEl = null, textEdge = 0, intro = false, paused = () => false } = {})
```

改动点（在现有代码上改）：

1. `uniforms` 名单加入 `'strength','focus','mode','intro','textEdge'`。
2. 新增 `measure()`，在 `resize()` 末尾调用：

```js
let f = focus.slice(), te = textEdge;
const measure = () => {
  const r = host.getBoundingClientRect();
  if (focusEl) { const e = focusEl.getBoundingClientRect(); f = [(e.left - r.left) / r.width, 1 - ((e.top + e.height / 2) - r.top) / r.height]; }
  if (textEdgeEl) { const e = textEdgeEl.getBoundingClientRect(); te = (e.right - r.left) / r.width; }
};
```

`focusEl` 的位置取元素左边缘、垂直中点。
3. 指针阻尼：`move` 只更新目标值 `target=[x,y]`；每次绘制前 `point[0]+=(target[0]-point[0])*0.08; point[1]+=(target[1]-point[1])*0.08;`。只要 `|target-point| > 0.001`，`activeUntil` 延长 200ms（保持 60fps 直到停稳）。
4. 加载扫入：`intro` 为 `true` 时，`introStart = performance.now()`；每帧 `k = Math.min((now - introStart) / 1200, 1)`，传 `1 - Math.pow(1 - k, 3)`；在 `k < 1` 期间按 60fps 绘制。`intro` 为 `false` 时始终传 `1`。
5. 每帧传入：`gl.uniform1f(uniforms.strength, strength); gl.uniform2f(uniforms.focus, ...f); gl.uniform1f(uniforms.mode, mode); gl.uniform1f(uniforms.textEdge, te);`。
6. 分辨率保持 0.5 倍，帧率保持空闲 30fps、活动 60fps。
7. 每个页面最多同时存在 3 个光场实例；不可见时停止绘制（现有逻辑保留）。

## 2. 三通道溯源线 `ProvenanceLines`

### 2.1 接口

```tsx
type ProvenanceLinesProps = {
  viewBox: string;                 // 与外层画面坐标一致，例如 "0 0 760 520"
  paths: string[];                 // 1–6 条 SVG path d
  surface: "dark" | "paper";
  state: "hidden" | "draw" | "flow" | "rest";

```

组件输出一个绝对定位、铺满父元素的 `<svg aria-hidden="true" class="prov" preserveAspectRatio="none">`。每条路径输出三个元素：

```svg
<path class="prov-base" d="…" pathLength="1"/>
<path class="prov-flow" d="…" pathLength="1"/>
<circle class="prov-dot" r="2.5"><animateMotion dur="900ms" begin="indefinite" fill="freeze" keyPoints="0;1" keyTimes="0;1" calcMode="spline" keySplines=".65 0 .35 1"><mpath href="#p-<id>-<i>"/></animateMotion></circle>
```

（第一条 `path` 加 `id="p-<id>-<i>"` 供 `mpath` 引用，`<id>` 用 React `useId()`。）

### 3.2 场景公共规则

每个场景是一个组件 `components/v4/scenes/Scene<Name>.tsx`，接口：

```tsx
type SceneProps = { locale: Locale; size: "full" | "compact"; step?: number; focusCite?: number | null; onCite?: (n: number | null) => void };
```

- `size="full"`：用在首页方案区（K-03，约 560×380）、方案详情首屏（K-05）、案例详情首屏（K-07）、首页首屏舞台（K-01，只用 `proposal` 与 `wiki`）。
- `size="compact"`：用在案例列表与首页案例区的暗色样机卡（K-06，约 360×225）。只保留主体区（下表“compact 保留”列），侧栏与抽屉隐藏。
- `step`：叙事进度（S1、S6 使用），未传入时等于最终态。
- 场景文字：`mk(sceneId, key, locale)` 从 `content/v4/mockups/<sceneId>.json` 读取；该键状态不是 `approved`/`class-a` 时返回 `null`，组件改画 `.mk-skel` 骨架线（行数与宽度按下表）。
- 系统名（窗口标题）一律用 `content/v4/cases.json` 中该案例的 `system` 字段（v1 定稿）。
- 指标数字一律取该案例的 `stats[n].value`（v1 定稿）。

### 3.8 缩放

样机在不同宽度下用整体缩放保持排版不变。实现方法固定为：外层 `.mk-scale`，内部样机固定设计宽度（full 560px、compact 360px）；组件 `components/v4/useMockupScale.ts` 用 `ResizeObserver` 读外层宽度，写 `--mk-k = 外层宽 / 设计宽`（上限 1）；样机 `transform:scale(var(--mk-k));transform-origin:top left`，外层 `height = 设计高 × --mk-k`。服务端渲染时 `--mk-k` 默认 1，外层 `overflow:hidden` 防止首帧溢出。缩放系数最小 0.62（手机 390 宽时 full 样机约 350px 宽）；低于 0.62 时改用 compact 版本。
