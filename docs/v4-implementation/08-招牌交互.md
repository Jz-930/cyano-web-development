# v4 实施手册 · 08 招牌交互（S1–S11）

> 每个交互写明：位置、触发、逐帧时间表、状态机、键盘、减弱动效、手机、性能预算、验收。
> 公共实现：`components/v4/useTimeline.ts`——给定步骤时间表，用 `requestAnimationFrame` 推进，把当前步骤写到容器的 `data-step`，CSS 根据 `data-step` 做过渡。所有视觉变化写在 CSS 里，JS 只切换状态。
> 公共规则：只在元素可见时运行（`IntersectionObserver`，阈值 0.4）；标签页隐藏时暂停；`prefers-reduced-motion: reduce` 时直接进入终态。
> **数字纪律**：动画中不出现任何中间数字（不做 0→99% 的计数滚动，不做 2 天→15 分钟的数字滚动）。数字只在终态出现，且必须是登记过的值。
> S4（延迟曲线）按 D-19 **取消**。

```ts
// components/v4/useTimeline.ts
"use client";
import { useEffect, useRef, useState } from "react";
export type Step = { at: number };            // 毫秒，自本段开始
export function useTimeline(ref: React.RefObject<HTMLElement | null>, steps: Step[], opts: { loopAfter?: number; maxLoops?: number; paused?: boolean; onLoop?: (n: number) => void }) {
  const [step, setStep] = useState(steps.length - 1); // SSR 与禁用 JS 时为终态
  const state = useRef({ start: 0, raf: 0, visible: false, loops: 0 });
  useEffect(() => {
    const el = ref.current; if (!el) return;
    const reduce = matchMedia("(prefers-reduced-motion: reduce)");
    if (reduce.matches) { setStep(steps.length - 1); return; }
    const s = state.current;
    const tick = (now: number) => {
      if (!s.start) s.start = now;
      const t = now - s.start;
      let k = 0; for (let i = 0; i < steps.length; i++) if (t >= steps[i].at) k = i;
      setStep(prev => (prev === k ? prev : k));
      if (opts.loopAfter && t >= opts.loopAfter) {
        s.loops++; opts.onLoop?.(s.loops);
        if (opts.maxLoops && s.loops >= opts.maxLoops) { s.raf = 0; return; }
        s.start = now;
      }
      s.raf = requestAnimationFrame(tick);
    };
    const run = () => { if (!s.raf && s.visible && !document.hidden && !opts.paused) { s.start = 0; setStep(0); s.raf = requestAnimationFrame(tick); } };
    const stop = () => { cancelAnimationFrame(s.raf); s.raf = 0; };
    const io = new IntersectionObserver(([e]) => { s.visible = e.isIntersecting; s.visible ? run() : stop(); }, { threshold: 0.4 });
    io.observe(el);
    const vis = () => (document.hidden ? stop() : run());
    document.addEventListener("visibilitychange", vis);
    return () => { stop(); io.disconnect(); document.removeEventListener("visibilitychange", vis); };
  }, [ref, steps, opts.loopAfter, opts.maxLoops, opts.paused]);
  return step;
}
```

## S1 首屏溯源舞台（首页首屏，K-01）

**载体**：`ProvenanceStage`（`05` 文件 §4）。容器 `.mk-stage` 带 `data-scene="proposal|wiki"` 与 `data-step="0..7"`。

### 时间表（每段 7600ms，两段交替）

| 步骤 | 起点 | 画面 | CSS 实现 |

### 循环与控制

- 交替播放：proposal → wiki → proposal …，**最多 3 个完整来回（6 段，约 46 秒）**后停在 proposal 终态。
- 暂停/播放按钮：舞台右下角，`button.stage-toggle`，32×32，玻璃小圆钮，图标 `Pause`/`Play` 16px；`aria-label` 甲类“暂停演示 / 播放演示”（`09` §1 `S1-pause`、`S1-play`）；`aria-pressed` 反映状态。暂停时停在当前步骤的终态。
- 离开视口暂停，回到视口从当前段步骤 0 重新开始。

### 悬停/聚焦引用角标

- 角标是 `<button class="mk-cite" aria-describedby=…>`。
- 悬停（100ms 意图）或聚焦角标 `[n]`：
  1. 叙事暂停（不改变步骤）。
  2. `ProvenanceLines focus={n-1}`：其余线降到 15%（220ms）。
  3. 对应来源卡移除 `.depth-back`，`transform` 加 `scale(1.04) translateX(12px)`，`z-index` 高于主窗口（320ms `--ease-spring`）；卡内第 2 行骨架线背景变 `--cyan-22`。
  4. 角标 `data-active="true"`。
- 离开 1.5 秒后恢复叙事（从当前段步骤 6 继续，即直接进入下一段）。

### 减弱动效

显示 proposal 终态：三张来源卡、全部溯源线（静态）、三句、7/7、已复核、指标为 `--ice`。没有循环，不显示暂停按钮。悬停角标只做高亮（线条透明度、卡片描边），不做位移与缩放。

### 手机（≤ 800px）

无来源卡、无溯源线；时间表只保留步骤 0、3、4、5、6、7（句子、检查、复核）。

### 预算与验收

- JS（S1 专属，不含场景组件）≤ 6KB gzip。只动 `transform`、`opacity`、`stroke-dashoffset`、颜色。
- 录屏两个完整来回；逐帧检查：任何时刻 H1 与导语对比度 ≥ 4.5:1；无布局抖动（Performance 面板 Layout Shift = 0）。

## S2 Cyano Core 四层点亮（技术页，K-09）

- **载体**：`.core-arch` 四列。
- **触发**：滚动。架构图进入视口后，计算进度 `p = clamp((innerHeight*0.75 - rect.top) / (rect.height + innerHeight*0.25), 0, 1)`（在 `scroll` 事件里用 rAF 合帧计算，只在可见时监听）。
- **画面**：`active = Math.min(3, Math.floor(p * 4))`；列 `i <= active` 为点亮态：标题 `--ink`、图形主色 `--brand` → `--cyan` 线条、列顶一个 6px 青点发光；`i > active` 为 `opacity:.45`。列间溯源线在相邻两列都点亮时进入 `flow`（每个间隙只播放一次）。
- **第 2 列漏斗**：点亮时 8 个小方块中 5 个变暗（`opacity:.25`）、3 个变 `--cyan` 并下落到漏斗底（`translateY`，320ms `--ease-spring`）。
- **第 3 列**：点亮时三个节点依次变青（间隔 200ms）。
- **第 4 列**：点亮时三条日志骨架线从左向右显现（`scaleX`，每条 200ms）。
- **键盘**：不需要（非交互）。
- **减弱动效**：四列全部点亮，静态。
- **手机**：四列竖排，同样按进度点亮。
- **验收**：从上往下滚动时四列依次点亮；往回滚动保持点亮（只增不减）。
