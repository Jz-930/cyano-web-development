### 2.5 删除死规则（阶段 5 结束时执行，阶段 1 先把脚本写好）

### 4.4 新的读取层 `site/lib/content-v4.ts`

```ts
import "server-only";
import { z } from "zod";
import v1copy from "@/content/v1/copy.json";
import overrides from "@/content/v4/copy-overrides.json";
import fresh from "@/content/v4/copy-new.json";
import rawCases from "@/content/v4/cases.json";
import type { Locale } from "./locale";

const L = z.object({ zh: z.string().min(1), en: z.string().min(1) });
const CaseSchema = z.object({
  slug: z.string(), order: z.number().int(), industry: z.string(), solution: z.string(),
  model: L, duration: L, title: L, system: L, profile: L,
  stats: z.array(z.object({ value: L, label: L, sourceId: z.string() })).length(3),
  before: L, after: L, outcome: L,
  images: z.array(z.string()).min(1), main: z.number().int(), demo: z.string().url().optional(),
  mockup: z.enum(["sales", "proposal", "wiki", "data", "property", "writing"]),
});
export const allCases = z.array(CaseSchema).length(6).parse(rawCases).sort((a, b) => a.order - b.order);

type Entry = { zh: string; en: string; status: "approved" | "class-a" | "pending" | "rejected"; ref: string };
const freshTable = fresh as Record<string, Entry>;
const overrideTable = overrides as Record<string, Entry>;

/** v1 定稿文字；负责人批准过改写时返回改写后的文字。 */
export function text(section: string, key: string, locale: Locale): string {
  const o = overrideTable[`${section}/${key}`];
  if (o && (o.status === "approved" || o.status === "class-a")) return o[locale];
  const base = (v1copy as Record<string, Record<string, { zh: string; en: string }>>)[section]?.[key];
  if (!base) throw new Error(`Missing v1 copy ${section}/${key}`);
  return base[locale];
}

/** 新增文字：必须存在且已批准，否则构建失败。用于整块都依赖它的位置。 */
export function copy(id: string, locale: Locale): string {
  const e = freshTable[id];
  if (!e) throw new Error(`Missing copy id ${id}`);
  if (e.status !== "approved" && e.status !== "class-a") throw new Error(`Copy ${id} is ${e.status}`);
  return e[locale];
}

/** 新增文字：未批准时返回 null，调用方整块不渲染。 */
export function copyIfApproved(id: string, locale: Locale): string | null {
  const e = freshTable[id];
  return e && (e.status === "approved" || e.status === "class-a") ? e[locale] : null;
}
```

- `copy-new.json` 与 `copy-overrides.json` 的初始内容：由 `09` 文件**全部行**生成，每行的 `status` 按 `09` 文件的“状态”列填写（`甲类` → `class-a`，`待批准` → `pending`）。负责人批准后，只改 `status` 为 `approved`（或按负责人改写后的文字替换 `zh`/`en` 并改为 `approved`），**不改代码**。
- 所有组件把 `import { text } from "@/lib/v1-content"` 改为从 `@/lib/content-v4` 引入；`cases()`、`solutions()`、`industries` 等改为读取 `content/v4/*.json`。完成后删除 `lib/v1-content.ts` 中的位置数组；`lib/v1-content.ts` 只保留 `href`、`t` 等与内容无关的再导出，或整个文件删除并修正引用。

### 4.6 中文标题断行 `Phrase`

**内容文件** `content/v4/zh-breaks.json`：键是完整标题文字，值是允许断开的词组数组。例如：

```json
{
  "为企业开发日常工作用得上的 AI。": ["为企业开发", "日常工作", "用得上的 AI。"],
  "企业使用 AI，需要处理哪些问题？": ["企业使用 AI，", "需要处理", "哪些问题？"],
  "我们如何开发和维护企业 AI 系统": ["我们如何", "开发和维护", "企业 AI 系统"]
}
```

**组件** `site/components/v4/Phrase.tsx`：

```tsx
import breaks from "@/content/v4/zh-breaks.json";
export function Phrase({ text, locale }: { text: string; locale: "zh" | "en" }) {
  if (locale !== "zh") return <>{text}</>;
  const parts = (breaks as Record<string, string[]>)[text];
  if (!parts) return <>{text}</>;
  if (parts.join("") !== text) throw new Error(`zh-breaks mismatch: ${text}`);
  return <>{parts.map((p, i) => <span key={i} className="phrase">{p}</span>)}</>;
}
```

`v4/base.css`：

```css
:lang(zh-CN) .phrase{display:inline-block}
```

**覆盖范围**：全站中文 h1、h2 中长度 ≥ 10 个字符的标题全部登记。生成清单的方法：构建后运行 `node scripts/list-zh-headings.mjs`（读取全部中文页面 HTML，输出所有 h1、h2 文本与字数），把 ≥ 10 字的逐条按“词不拆开”的原则写进 `zh-breaks.json`（断点放在词组之后、标点之后；助词“的”“了”跟前一个词）。组件里所有中文 h1、h2 的文字都用 `<Phrase text={…} locale={locale}/>` 渲染。

## 6. 字体与首屏性能（W4-03、F-07）

### 6.1 中文字重收窄为 400–500

全站中文只用两个字重：正文 400，强调与小标题 500。大号中文标题也用 400（`03` 文件 §5 排版表已按此规定）。

**文件** `site/scripts/subset-font.mjs`：

1. 删除从 `site-copy-v2.json`、`solutions-v2.json` 等旧文件收集文字的代码。
2. 改为两遍构建：第一遍 `next build` 后读取 `.next/server/app/index.html`（中文首页），提取 `<body>` 内全部文本节点、`alt`、`aria-label`、`title`、`placeholder`、`content` 属性里的字符，加上 `content/v4/copy-new.json` 中首页区块用到的全部中文（首页交互隐藏态，例如选项卡未选中的面板），得到 **core** 字符集；读取其余全部中文页面 HTML 与 `content/v4/**/*.json`、`content/v1/**/*.json` 的中文，减去 core，得到 **ext** 字符集。
3. 子集化时限制字重轴：

```js
const core = await subsetFont(src, coreText, { targetFormat: "woff2", noHinting: true, variationAxes: { wght: { min: 400, max: 500 } } });
```

ext 同样处理。
4. 输出文件名带内容哈希，写回 `app/styles/cjk-font.css`（`font-weight: 400 500;`）。

**文件** `site/package.json` 的 `build` 改为：

```json
"build": "node scripts/validate-v4.mjs && node scripts/build-v3-media.mjs && next build --webpack && node scripts/subset-font.mjs && next build --webpack && node scripts/scan.mjs"
```

（`validate-v4.mjs` 见 §9.4。第二遍构建使用新子集。）

**判定**：中文首页首屏字体（Noto core + Inter + Manrope + Mono 中首屏实际请求的文件）合计 ≤ 150KB。如果仍超过：把 core 字符集改为只取首页**前两屏**（`window.innerHeight × 2` 以内）出现的字符，其余字符归入 ext（ext 在首页也会按 `unicode-range` 按需下载）。再超过就报告，不要自行改字体。

### 6.2 回退字体度量（防止字体到达时整页重排）

**文件** `app/styles/cjk-font.css` 由脚本生成，在脚本模板里追加：

```css
@font-face{font-family:"Noto Sans SC Fallback";src:local("Microsoft YaHei"),local("PingFang SC"),local("Noto Sans CJK SC"),local("Source Han Sans SC");ascent-override:116%;descent-override:29%;line-gap-override:0%;size-adjust:100%}
```

**文件** `v4/tokens.css` 中的字体栈（`03` 文件 §1 已包含，这里说明来源）：

```css
--sans: var(--font-sans), "Noto Sans SC Subset", "Noto Sans SC Fallback", sans-serif;
--display: var(--font-display), "Noto Sans SC Subset", "Noto Sans SC Fallback", sans-serif;
--mono: var(--font-mono), var(--sans);
```

拉丁字体由 `next/font/local` 自动生成回退度量（`adjustFontFallback` 保持默认，不要关闭）。

### 6.3 限制 `text-wrap`

- 全站删除 `text-wrap:pretty`。
- `text-wrap:balance` 只允许出现在 `h1, h2, .lede` 三类选择器上（`03` 文件 §5 已写好）。旧文件里其他位置的 `text-wrap` 全部删除。

### 6.4 等宽字体

`jetbrains-mono-latin.woff2` 是静态 500。全站等宽字只用 500，`font-weight:600` 及以上的等宽规则全部改成 500（否则浏览器合成粗体）。

### 6.5 验收

`10` 文件 §3 阶段 1：手机首页 TBT ≤ 200ms（4 倍 CPU 降速、Slow 4G 网络，取 5 次中位数）；中文首页首屏字体 ≤ 150KB；`/about`、`/technology` 首屏字体 ≤ 150KB；Performance 面板中字体到达后不出现 > 50ms 的布局任务。
