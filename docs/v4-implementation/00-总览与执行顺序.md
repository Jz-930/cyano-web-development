## 2. 红线（违反任何一条，该提交直接退回）

1. **不改事实、不加数字。** 页面上出现的每个数字必须在 `content/sources.md` 登记过。本手册里出现的所有数字都已核对；手册没给的数字一律不写。样机里需要“看起来像数据”的位置，用文字或图形表示，不编数字。
2. **文字只有三个来源**：`site/content/v1/*.json`（v1 定稿）、`09-文案对照稿.md` 里状态为“已批准”或“甲类”的行、法律正文。除此之外不新增任何一句话，包括 alt、aria-label、title、description、样机界面文字。
3. **不出现**：真实客户公司名、创始人真名或照片、服务器或机房所在地、价格、资质与奖项、竞争对手公司名、“唯一 / 第一 / 最 / 领先 / 保证 / 绝对 / 永远 / 全链路”等词。
4. **颜色只用 Token。** 新写的 CSS 里不允许出现 Token 以外的十六进制颜色（`03` 文件定义了全部 Token，包括透明度变体）。不允许紫色、粉色、彩虹色渐变。
5. **不使用生成图、库存图、3D 渲染图。** v4 的主视觉全部用 HTML/CSS/SVG 重建界面加 WebGL 光场完成。真实截图只用在“界面实录”、图廊和灯箱里。
6. **不引入新的 npm 依赖**，除非本手册明确写了包名和版本（只有 `02` 文件里的 `prettier` 与 `potrace` 两个开发依赖）。不引入动画库（GSAP、Framer Motion、Lottie 等都不要）。
7. **所有动效只改 `transform`、`opacity`、`filter`、`clip-path`、`stroke-dashoffset`、`background-position`。** 不对 `width`、`height`、`top`、`left`、`margin`、`box-shadow` 做逐帧动画（`box-shadow` 只允许在 `:hover` 过渡里一次性变化）。
8. **每个动效都有 `prefers-reduced-motion: reduce` 的替代态**，写法见 `04` 文件第 1 节。禁用 JavaScript 时，所有内容必须可见（动效的初始隐藏态只能在 `html.js` 存在时生效，见 `04` 文件第 3.15 节）。
9. **不在 `public/` 下放任何样张、草稿、测试页面。** 样张只放在只在开发环境可访问的路由里（见本文件第 4 节阶段 3）。
10. **不提交、不推送** `main` 分支；不自行合并。每个阶段一个分支、一个合并请求，验收通过后由负责人合并。

- 每个 F 编号、每个 K 编号、每个 S 编号单独一个提交，提交信息格式：`v4(F-03): fix about name-story heading color`。

## 6. 遇到问题怎么办

| 情况 | 处理 |
|---|---|
| 手册写的文件或选择器在代码里找不到 | 用 `grep -rn` 搜索手册里给的类名或文字；仍找不到，在合并请求里列出，**不要自行找替代位置** |
| 手册给的数值实现后效果明显不对（例如对比度不达标、文字被遮挡） | 不改数值，截图记录，在合并请求里提出，等回复 |
| 需要一句手册里没有的文字 | 先不写，位置留空不渲染（不要放占位文字），在合并请求里列出需要的文字与位置 |
| `09` 文件里的某行还没批准 | 页面上用 v1 原文；如果该块在 v1 里不存在，整块不渲染 |
| 浏览器不支持某个 CSS 特性 | 按手册写的回退写法；手册没写回退的，在合并请求里提出 |
| Next.js 用法与记忆不符 | 先读 `site/node_modules/next/dist/docs/` 里对应章节（本版本有破坏性变化），按文档写 |

## 7. 术语对照

| 本手册写法 | 含义 |
|---|---|
| N0–N3 | 暗色层级 `--n0`…`--n3` |
| P0–P3 | 纸面层级 `--p0`…`--p3` |
| 暗区 | 背景为 N0–N3 的区块（首屏、嵌入暗面板、收尾区、页脚） |
| 纸面区 | 背景为 P0–P3 的区块 |
| 嵌入暗面板 | 纸面区里一块 24px 圆角的暗色大面板（例如首页“四个工程问题”） |
| 三通道 / 溯源线 | Logo 左侧三条平行通道的母题：三条 1.25px 线，带 40px 流动光段，组件 `ProvenanceLines`（`05` 文件 §2） |
| 样机 | 用 HTML/CSS 重建的产品界面局部，组件 `Mockup*`（`05` 文件 §3） |
| 甲类文字 | 功能性提示语（错误提示、按钮无障碍标签、暂停/播放），默认可用 |
| 乙类文字 | 营销与说明文字，必须负责人批准 |
