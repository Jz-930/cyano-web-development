## 4. 设计方向

### 4.1 保留

色彩 Token、明暗交替、桌面 80px 边距、胶囊按钮、“小方块 + 小标签 + 细体大标题”的标题组、案例卡结构、合作方式页的流程列表、“2 天 → 15 分钟”这张卡的表达方式。这些是评审点名做得好的。

### 4.2 新母题：溯源线

Cyano 与通用模型的区别是“回答有据可查、过程有校验”（信息支柱 ③④）。把这件事画成全站统一的图形语言：

- **元素**：一条薄荷绿细线，从“结果里的一句话”连到“它出自哪份资料”；被引用的文字带薄荷绿底色高亮；校验点是线上的一个小圆点。
- **用法**：首屏主视觉、各方案工作流图、技术页架构图、案例标注截图、卡片悬停态，都用这套线、高亮、圆点。
- **为什么是它**：只属于这家公司的业务，不是装饰；能动（线逐段画出、高亮逐字出现）；不涉及地理意象。

### 4.3 工程感的细节

- 序号、指标单位、元数据、代码标签用 JetBrains Mono（原方案 §7.4 已定，初版没有用）。
- 深色区保留极淡的网格线，图形对齐到网格。
- 图标只在导航和列表里用；凡是“解释一件事”的地方用自绘图，不用 lucide 图标加文字。

### 4.4 亮点前置

文案不动，改变呈现的权重：

| 亮点 | 现在 | 第二版 |
|---|---|---|
| 2 天 → 15 分钟 | 首屏右下角一张小卡 | 首屏主视觉的结论，随演示跑完后定格放大 |
| 80% 常见工单自动处理、3 秒内 | 案例卡右上角 25px | 首页“结果带”三个大数字之一，Display 字号 |
| 团队硬事实（6 年+、AI 研发、世界 500 强） | 四个等大的数字，两个 100% 并排 | 改成一句话加三个事实标签，不再四等分（措辞待你确认，见 §10） |
| Cyano Core 的成本与延迟优势 | 技术页四个孤立数字 | 一张可拖动的对比图：对话轮数从 1 到 100，两条曲线 |
| 真实系统界面 | 缩小、倾斜、看不清 | 带编号标注的大图，每个标注一句说明 |

## 5. 字体系统（替换原方案 §7.4 的字号规则）

字体族不变：Manrope（英文标题与数字）、Inter（英文正文）、思源黑体（中文）、JetBrains Mono（技术标签）。用 `:lang(en)` 与 `:lang(zh)` 分开两套参数。

### 5.1 英文

| 级别 | 字号 | 字重 | 行距 | 字距 |
|---|---|---|---|---|
| Display | clamp(44px, 4.4vw, 68px) | 300 | 1.06 | -0.02em，另加 `word-spacing: 0.06em` |
| H1 内页 | clamp(36px, 3.6vw, 56px) | 300 | 1.1 | -0.02em，同上 |
| H2 | 40px（手机 30px） | 400 | 1.15 | -0.015em，`word-spacing: 0.04em` |
| H3 | 28px（手机 24px） | 400 | 1.2 | -0.01em |
| H4 卡片标题 | 20px | 500 | 1.3 | 0 |
| 导语 | 19px | 400 | 1.45 | 0 |
| 正文 | 16px，文章 17px | 400 | 1.55 | 0 |
| 小字 | 14px | 400 | 1.5 | 0 |
| 说明、脚注 | 12–13px | 400 | 1.45 | 0.01em |
| 大写标签 | 12px | 600 | 1.3 | 0.08em |

- 行长：正文 `max-width: 66ch`，导语 `52ch`。
- 断行：标题 `text-wrap: balance`，正文 `text-wrap: pretty`；“AI‑drafted”“evidence‑based”用不换行连字符；“15 minutes”“3 seconds”这类数字加单位用不换行空格；英文标题的断行单独写，不继承中文的 `\n`，去掉 H2 上的 `white-space: pre-line`。
- 规则：全站句首大写，只有产品名和职位用 Title Case；日期写 `Nov 10, 2026`；站内链接用 →，新窗口用 ↗，都用图标；句子里用 and，栏目名里用 &。
- 标签列宽按英文长度重排：流程标题列 280–320px；指标说明放到数字下方。

### 5.3 落地要求

- 字号、行距、字距只允许来自上面两张表，写成 Token；组件里不出现裸的 `font-size`。

- 间距回到 8pt 体系，区块上下间距桌面 144px、手机 88px（原方案 §7.5）。
