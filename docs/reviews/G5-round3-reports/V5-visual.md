## 0. 一句话结论

v3 的底子已经打好：Token、纸面卡片、深色舞台、一个按钮体系、字体层级，这些都比 v2 干净、克制。**但“大美术”这一层基本空缺。** 全站真正的主视觉只有首页右侧一块截图卡片，其余 9 类页面的首屏都是同一张小线稿，而且被裁出了屏幕右边缘。光场很弱，看起来只是右上角一抹青色。“三通道”这根支柱在画面里几乎看不到。手机首页首屏两种语言都有文字叠字。结论：**不通过**（均分 3.8，四个维度低于 5）。

## 1. 十二项评分

### R-VIS（通过线：每维 ≥ 5，均分 ≥ 6）

| 维度 | 分 | 理由 |
|---|---|---|
| 层级 | **5** | 标题、导语、正文三级清楚。Manrope 细体大标题有气质，中文标题也不再落到宋体。扣分有两处：内页首屏结构完全一样（面包屑 → 标签 → H1 → 导语 → 同一张线稿），页面之间没有主次；纸面区的区块都是“标签 + H2 + 一排白卡”，读者分不出哪一块最重要。 |
| 节奏 | **4** | 明暗只有“暗首屏 → 长纸面 → 一块暗面板 → 暗收尾”这一种节拍。纸面段之间只靠 P0/P1 两档极近的灰来分隔，几乎看不出切换。首页首屏上下各约 150px 空场。“我们是谁”左栏约 360px 全空。About、方案详情有连续 2–3 屏的白卡列表，没有一个视觉峰值。 |
| 品牌感 | **4** | 深青黑加冷灰纸面，配色统一，看得出是同一家公司。但把 Logo 遮住，这套页面和任何一家深色 SaaS 模板很难区分。品牌光场只是右上一抹弱光；“三通道”母题只在首屏卡片中间那 60px 宽的三条短线上出现。没有一个元素能让人记住 Cyano。 |
| 美术融合 | **3** | 同一张 `EngineeringDiagram`（`variant` 参数被组件忽略）出现在全部内页首屏、首页方案卡、6 张文章封面上，总共十几次。它在内页首屏还被裁到屏幕外。三类图像语言没有统一：真实截图被放在灰色托盘里，铅笔素描人像，线稿示意图。截图本身配色各不相同（钴蓝、橙、绿），没有做样机化处理。 |
| 移动端 | **3** | 中英文首页首屏都有叠字（“定制开发 · 试点 · 托管服务”压在“15 分钟”和截图上；英文压在 “View full screen” 按钮上）。产品卡被下面的纸面直接切断。案例详情首屏线稿压在标签文字上。对比表直接截断，没有可横滑的提示。截图在手机上缩到 3–4px 的字。 |
| 精致度 | **4** | 纸面卡片的阴影和描边很到位，按钮做工统一。但能看到不少粗糙之处：首屏界面截图是放大后的位图，明显发糊（裁图 440×310px，显示约 527×310）；延迟图圆点被拉成椭圆（`preserveAspectRatio="none"`）；“点击放大”胶囊有一半在截图外；案例列表卡片不等高；“6 个”的单位和数字之间空了一大截；行业标签换行成两行的方框；联系表单仍是原生下拉。 |

**R-VIS 均分 3.83，层级 5 / 节奏 4 / 品牌感 4 / 美术融合 3 / 移动端 3 / 精致度 4，不通过。**

### 附加维度

| 维度 | 分 | 理由 |
|---|---|---|
| 实力感 | **4** | 访客能看出团队做事克制、懂排版，但看不出“开发能力很强”。全站唯一的交互图表是两条直线；唯一的交互演示（Wiki 案例）默认状态是一大块白色空框。和 Linear 或 Stripe 那种“产品本身就是主视觉”的说服力差距明显。 |
| 信息可视化 | **3** | 能一眼看懂的图形只有延迟折线和四根记忆条。流程是“图标 + 标题”的四张卡，前后对比是两张纯文字卡，合作方式是普通表格，架构是四行列表。计划里写的甘特式对比、真实比例的前后时间轨、架构图、分屏对照，都没有落地。 |
| 质感 | **4** | Token 落地准确：N0–N3、P0–P3、纸面卡两层阴影、玻璃页头、内高光都有。不足在于：深色区几乎是一块平板（暗面板里没有光场，也没有描边被照亮的效果）；颗粒肉眼看不见；没有景深；截图没有任何渲染处理。 |
| VI 系统一致性 | **4** | 能用三句话描述：①深青黑舞台加冷灰工程纸面；②只用一种青色做强调，琥珀表示人工、玫红表示旧做法；③细线工程图加真实界面截图。但计划自己定的三根支柱“光 / 通道 / 纸面”只看得到“纸面”。“光”太弱，“通道”几乎不存在，所以这套 VI 是靠“统一的克制”成立的，不是靠“可识别的母题”。 |
| 主视觉与大美术 | **2** | 首页首屏的产品卡是全站唯一像样的主视觉，可它是静态的，而且发糊。内页首屏、方案总览、案例列表、文章封面、团队、收尾 CTA 都没有大画面，全是同一张小线稿或缩略截图在充数。 |
| 点缀细节 | **3** | 有玻璃页头、产品卡玻璃、纸面卡阴影、点阵网格、CTA 卡细描边。没有：可感知的背景光晕、渐变描边、发光边缘、分隔线上的光点、指针跟随的光斑、景深。现在的问题不是做多了显得廉价，而是几乎没做，画面显得“素”而不是“高级”。 |

## 3. 主视觉与大美术专项

总原则：Cyano 卖的是“把散乱资料变成有据可查的工程产出”。所以主视觉的主角应该是**真实界面加上被画出来的溯源过程**，而不是抽象的光或 3D 物体。光场负责气氛，三通道负责叙事，界面样机负责证据。

### 3-1 首页首屏（现状：静态、发糊的截图卡；光很弱）

- **构图**：左 5 栏文字保持不变。右 7 栏做一块约 760×520 的“产品舞台”，舞台左缘要伸到文字栏后面 40px，形成前后叠压的纵深。舞台由三层组成：
  - 后层：两张略微倾斜的来源卡（PDF 页面局部、表格局部），旋转 −4° 和 +3°，透明度 70%，在景深里模糊 2px；
  - 中层：主界面窗口（N2 外框、24 圆角、10px 内边距，左上角用等宽字写 `PROPOSAL BUILDER`），里面是**用 HTML 重建的**方案初稿界面，真文字 13–14px；
  - 前层：一张玻璃小卡“校验 7/7 · 引用 99%”，悬在主窗口右下角，外出 32px。
- **镜头与透视**：正视，不用 3D 透视（计划禁止旋转的 3D 物体）。纵深靠叠压、模糊和阴影来做。
- **光源与材质**：光场的三条亮流线从右上进入，穿过后层来源卡，汇聚到主窗口左边缘的一个光点。主窗口顶边 1px 内高光，左上描边带 30% 青色渐变（见 §4）。
- **颜色**：N0 底，界面 N2/N3，引用高亮用 `--cyan` 12% 底色加 1px 下划线，人工复核点用琥珀。
- **与文字的关系**：文字栏背后的亮度压到 N0，保证对比度；H1 的“AI。/ everyday work.”青色和光场同色，呼应。
- **动静**：环境动画加叙事循环，一个周期 7 秒：来源卡依次亮起 → 通道光点沿线移动到初稿 → 初稿里对应句子出现青色高亮和角标 [1] → 校验计数从 0 跑到 7 → 数字定格。之后切到 Wiki 案例。提供暂停按钮；`reduced-motion` 时只显示终态。
- **实现**：HTML/CSS 重建界面加 SVG 通道线（stroke-dashoffset），光场继续用现有 WebGL，提高亮度并加汇聚点。不用位图截图。

## 4. 点缀细节专项（可直接执行的规范）

### 4-1 磨砂玻璃

| 用在哪 | 参数 |
|---|---|
| 吸顶页头（暗区） | `background:rgba(11,17,23,.58)`；`backdrop-filter:blur(20px) saturate(150%)`；底部 1px `rgba(255,255,255,.06)` |
| 吸顶页头（纸面） | `background:rgba(243,246,247,.72)`；`blur(16px) saturate(140%)`；底部 1px `rgba(12,28,36,.08)`（**文章页现在是实心暗条，要改**） |
| 首屏产品舞台外框、首屏指标小牌、技术页汇合点小窗、案例封面指标牌 | N1 58%；`blur(20px) saturate(150%)`；1px `rgba(255,255,255,.08)`；顶部内高光 1px `rgba(255,255,255,.10)`；外阴影 `0 30px 80px -30px rgba(0,0,0,.7)` |
| 灯箱遮罩 | N0 70%；`blur(12px)` |

**变廉价的边界**：玻璃下面必须有光或内容可透；平底上的玻璃等于灰卡。同一屏最多 3 块。玻璃不叠玻璃。不在纸面区里给卡片用玻璃。模糊半径不超过 24px，否则发脏。饱和度不超过 160%。

### 4-2 背景光晕

| 位置 | 尺寸 | 颜色与透明度 | 运动 |
|---|---|---|---|
| 首屏右上（光场主能量） | 约 900×700，椭圆 | 青 `#38C8E0` 中心 22% → 0；掺冷蓝 ≤10% | 20–30 秒漂移一周期；指针 ±2% 视差；滚动改变相位 |
| 首屏产品舞台背后 | 舞台外扩 120px | `--cyan` 10% 径向，偏左下 | 跟随叙事节拍呼吸（±3%） |
| 纸面顶部“光漏” | 全宽 × 240px | 青 4% 线性 → 0 | 静态 |
| 嵌入暗面板右上 | 600×400 | 青 12% | 指针进入面板后跟随，`lerp` 0.08 |
| 收尾 CTA 按钮背后 | 160px 圆 | 青 18% | 悬停扩大到 220px，240ms |

**变廉价的边界**：光晕只用青色族（加 ≤10% 冷蓝），不许出现紫、粉的“AI 渐变”。纸面区不放彩色光晕，只放 4% 光漏。光晕不能压在正文后面让对比度低于 4.5:1。同屏不超过两处光源。不做旋转、脉冲闪烁之类的装饰循环。

### 4-3 渐变线与渐变描边

| 元素 | 方向 | 颜色停靠点 |
|---|---|---|
| 首屏产品舞台描边 | 135°，左上 → 右下 | `rgba(56,200,224,.45)` 0% → `rgba(255,255,255,.08)` 35% → `rgba(255,255,255,.04)` 100% |
| 收尾 CTA 卡描边 | 90°，左 → 右 | `rgba(255,255,255,.06)` 0% → `rgba(56,200,224,.35)` 70% → `rgba(255,255,255,.06)` 100% |
| 深色卡悬停描边 | 以指针为中心的径向渐变 | 指针处 `rgba(56,200,224,.5)`，半径 180px 内衰减到 `rgba(180,220,235,.10)` |
| 分屏中线、暗面板分隔 | 竖直 | 透明 0% → 青 40% 50% → 透明 100% |
| 三通道线 | 沿路径方向 | 底线 `--deep` 1.25px，流动段是 40px 长的 `transparent → --cyan → transparent` |

**变廉价的边界**：渐变描边只给“主角”元素（每屏 ≤2 个），普通卡片保持纯色细描边。渐变只在一个色相内变化，不做彩虹。按钮禁止渐变底（计划已定）。渐变线宽 ≤1.5px，太粗会像霓虹灯。

### 4-4 颗粒

- **暗区**：shader 里叠 2.5–3% 单色噪点（现在约 1.8%，`(hash-.5)*.018`，肉眼不可见），尺寸 1px，每帧变化。静态海报里也要烘焙同样的颗粒。
- **纸面**：不加颗粒。
- **边界**：超过 4% 就像旧电视。纸面加颗粒会显脏。颗粒不能有彩色。

### 4-5 景深

- 只用在首屏舞台和案例封面的“后层”元素：`filter:blur(2px)`，透明度 0.7，缩小到 0.96。
- **边界**：同一画面只分前、中、后三层。正文和可交互元素永远不模糊。不做滚动视差位移（计划禁止文字视差）。

### 4-6 发光

| 元素 | 参数 |
|---|---|
| 生效门禁、通道光点、选中的来源项 | `box-shadow:0 0 0 1px rgba(56,200,224,.6),0 0 16px rgba(56,200,224,.35)` |
| 深色区主按钮悬停 | `0 0 0 1px rgba(56,200,224,.5),0 0 24px -4px rgba(56,200,224,.45)` |
| 大号浅青数字 | `text-shadow:0 0 24px rgba(165,236,245,.25)`（只用于暗区里 ≥48px 的数字） |

**边界**：纸面区不用发光，改用描边转青加阴影加一档。发光半径不超过 24px。同屏发光元素不超过 3 个。发光表示的是状态（选中、生效、悬停），不能当常态装饰。

### 4-7 分隔线

- **纸面区段落间**：1px `rgba(12,28,36,.08)` 全宽线。左端 80px 处放一个 5px 青色实心点，作为“通道起点”；滚动到这里时，一个光点从左到右走一遍（900ms，只走一次）。
- **暗区**：1px `rgba(180,220,235,.10)`。
- **数据带竖分隔**：保持现在的 1px，高度和数字块对齐。
- **边界**：一屏最多两条带光点的分隔线，其余用静态线。不要把每张卡都加上分隔线和光点。

### 4-8 网格

- **工程纸点阵**：24px 间距，1px 点，`rgba(12,28,36,.06)`，四周 20% 范围径向渐隐。只放在图解、界面样机背后，不放在正文背后。
