英文标题字距问题的成因（在 `/en/technology` 实测）：

- 标题字体是 Manrope，空格宽度只有 0.20em（Inter 是 0.28em）。
- 全局规则 `h1,h2,h3,h4{letter-spacing:-.035em}` 同时收紧了字母和空格，42px 的 H2 每个字符收紧 1.47px，`word-spacing` 为 0，没有补偿。
- 结果是词间距只剩约 0.13em，“Select context for each task”读起来像“Selectcontext foreach task”。
- 同一条负字距规则也作用在中文标题上（50px 标题收紧 1.25px）。

手机 375px 与 390px 视口下 `scrollWidth` 等于视口宽度，没有横向溢出。
