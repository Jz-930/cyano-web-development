## 2. 问题清单（按严重度排序）

### 严重

1. **【中文】等宽标签回退成宋体。**
   - 位置：`zh-home-d-01`（舞台标题「智能标书与方案生成系统」「实时引用溯源链路」）、`zh-home-d-05/06`（「专业服务与投研」「零售与供应链」）、`zh-home-d-09`（「交付周期比例标尺」「模式 01 · 资产归客户所有」）、`zh-home-d-11` / `zh-about-d-03`（「专长：…」）、`zh-cases-d-04`（「自动提取」「百万字级」）、`zh-case-proposal-d-05`（「15 分钟初稿 + 人工复核」）、`zh-home-mobile-02/06/07/09`。
   - 现象：这些标签是粗宋体 / 仿宋字形，与正文黑体混排，像字体加载失败。
   - 原因：`site.css:168` 的 `.font-mono-tech` 字体栈是 `var(--font-mono), ui-monospace, …, monospace`，没有中文字体，Windows 上落到 NSimSun。
   - 建议：等宽栈在 `monospace` 之前补 `"Noto Sans SC Subset","PingFang SC","Microsoft YaHei"`；或者中文标签不套等宽类，改用黑体 600 + 0.04em 字距。

2. **【中英】白底插画露出矩形底板。**
   - 位置：`en-case-proposal-d-01`、`en-cases-d-01`、`en-case-wiki-d-01`、`en-insights-d-01`、`en-article-d-01`、`en-solution-doc-d-01`、`en-services-d-01/02/04`、`zh-about-d-01`、`zh-contact-d-01`、`en-home-d-04`、`zh-home-mobile-05`。
   - 现象：图片自带约 `#F7F7F7` 带噪点的底，在 `#FFF` 页面上显出一块约 565×315 的灰白矩形，边缘是模糊羽化。
   - 原因：`site.css:158` 的 `mix-blend-mode: multiply` 去不掉非纯白底。
   - 建议：换真透明通道的抠图；或重渲染到纯 `#FFFFFF` 再加 `mask-image` 径向渐隐；或干脆放进有描边的图框，让「框」成为设计的一部分。

3. **【中英】图像语言过多，约 12 种。**
   - 清单：①深色光纤「C」；②白底彩虹全息玻璃带（`en-home-d-04`）；③白底棱镜 + 橙粉紫蓝光束（cases）；④青 / 钴蓝玻璃方块与环（engagement）；⑤青色碎片汇入堆叠（services）；⑥深色电影感碎屑棱镜（`zh-home-d-07`）；⑦青紫粉橙线框波（`zh-home-d-07`、`zh-about-d-04`）；⑧线稿同心圆示意图（`en-technology-d-01`）；⑨深色玻璃层板 + 霓虹光柱；⑩深色霓虹玻璃文章封面；⑪米色 / 鼠尾草绿水彩人物；⑫白底粉红紫节点网（insights）。外加玻璃 C + 珠子。
   - 建议：收敛到两种。A = 深色场景里的青色玻璃 / 光纤 3D（只用于首屏、收尾、技术页）；B = 单色线稿示意图（⑧这种，用于所有浅色页）。②③⑦⑫的品红、粉、橙全部退场。

4. **【中英】首页首屏：主视觉压字，且几乎没有动效。**
   - 位置：`zh-home-d-01`、`en-home-d-01`、全部 `*-heroframe-*`。
   - 现象：光纤「C」从 x≈550 起向左渗入文字区。中文副标题「也提供托管式 AI」、英文「proposal drafting,」「managed AI workflows,」直接压在亮青丝束上。「C」下半被产品舞台框截断。米 / 蓝 / 青色珠子观感像装饰小球。400 / 1500 / 3000 / 8000ms 四帧除了计数「5/7 ↔ 7/7」和几根极淡横线外完全相同。
   - 建议：美术右移并在 x<720 处用遮罩渐隐到 0；去掉珠子或统一成一种青色；动效二选一——让舞台内部真的动（来源逐条点亮、截图区域高亮跟随），或让光纤有缓慢流光，并提供 reduced-motion 静帧。

5. **【中英】嵌入的「真实界面」截图读不了。**
   - 位置：`zh-home-d-01/02`、`en-home-d-02`、`zh-home-d-05/06`、`en-cases-d-02`、`en-solution-doc-d-04/05`；移动端 `zh-home-mobile-01/02/07/08/09`。
   - 现象：桌面 1:1 下截图内文字约 5–6px，移动端等效 3px 以下。最有说服力的证据变成了色块纹理。深色截图上下还各有约 50px 空带。
   - 建议：每张卡只裁一个约 600px 宽的焦点区域，放大到 ≥ 0.8 倍；或用 HTML 重建关键面板（来源链、校验清单）；移动端只放一个局部特写。

6. **【中英】技术页交互曲线有四处硬伤。**
   - 位置：`en-technology-d-04`、`zh-technology-d-04`、`en-technology-mobile-06`。
   - 现象：
     - 刻度「Turn 1 / Turn 50 / Turn 100」是衬线体（`TechVisuals.tsx:319–325` 写的 `fontFamily="monospace"`，同样落到宋体），中文页没有翻译；
     - 青色圆点（y≈677）在青色线（y≈648）下方约 30px，不在线上；

   - 建议：重画——1.5px 线 + 线下渐变面积，纵轴写 ms，圆点吸附到曲线并带数值标签，刻度用站内等宽字 12px，中文本地化。

7. **【中英】Services 页同一张插画重复 5 次，右侧大面积留空。**

## 3. 质感专项诊断

### 廉价感 / 塑料感 / 粗糙感的来源

- **底色。**
  - 浅色只有 `#FFFFFF` 与 `#F6FAFC` 两级，亮度差约 2%，屏幕上几乎分不出层（`zh-home-d-04` y=517 的分界要靠发丝线才看得见）。
  - 深色用纯 `#000000`（`zh-home-d-07/08`、页脚），没有色相也没有纵深，上面的字像贴在黑卡纸上。

- **渐变。**
  - 主按钮的青渐变（`site.css:210`）是「糖果胶囊」，全站最塑料的元素。
  - 交付周期条的青→钴蓝→紫（`zh-home-d-09`）、青→琥珀（`zh-home-d-10`），和前后对比条的粉→橙→黄（`en-case-proposal-d-05`），是饱和纯色横条，像图表库默认配色。
  - 收尾区 `#000→#0D1D38` 的对角渐变本身可以，但与首屏的蓝黑、对比区的纯黑不是同一种黑。

- **配色来源。** `tokens.css` 的主色之外定义了钴蓝、紫、琥珀、玫红 4 组「多色光谱」，图像里又带进品红、粉、橙、金、米色。颜色来自生成图，不是来自品牌。

- **生成图的渲染与边缘。**
  - 白底图自带灰白底板和羽化边（第 2 条）。
  - 光源方向、阴影硬度、饱和度每张不同：`en-home-d-04` 高饱和全息，`en-engagement-d-01` 写实玻璃 + 落地阴影，`en-services-d-01` 半透明无阴影。
  - 首屏「C」在 1440 宽下偏软，像放大过；珠子材质（米色珍珠 / 蓝玻璃 / 青塑料）混杂。
  - 水彩人物是典型生成插画观感。

- **阴影。**
  - `--shadow-card` 8% 透明度、-28px 扩散，实际不可见，浅色卡片没有高度。
  - 截图卡下方反而有一团很大很虚的灰影（`zh-home-d-05` y 400–440、`en-case-proposal-d-04` y 578–640），像 2018 年的设计平台样机图。

- **描边。**
  - 全站只有 10% 黑的 1px 发丝线，既做分隔，又做卡片，又做表格。
  - 黑底上的 1px 白 14% 方框（`en-technology-d-05`）没有内发光和顶部高光，像线框稿。

- **卡片。**
  - 浅色卡 = 白底 + 发丝线 + 直角或 20px 圆角混用（`en-engagement-d-04/05` 是直角格子，`en-contact-d-01` 是 24px 圆角）。
  - 深色内嵌卡是纯黑圆角块直接放在白底上（`en-case-proposal-d-02`），没有边缘处理，像一块黑贴纸。

- **按钮。** 两套主按钮；选型器的选中态是 `#0E7490` 实心胶囊 + 白字，未选是白底灰描边（`en-engagement-d-02`），可用但没有做工。

- **图标。** 线性细图标（数据库 / 层 / 盾，`en-technology-d-02`）孤零零放在行尾，24px、灰色，可有可无；「人工复核」小人图标是琥珀色，与其它不同。

- **图表。** 见第 6 条。上下文预算条（`en-technology-d-03`）是四段纯色圆角条，无刻度、无数值。

- **动效静帧。** 首屏 8 秒内只有一个数字在变。

### 有质感、应保留的做法

- 细字重展示字体做大标题（`en-case-proposal-d-01`、`en-technology-d-01`），字距紧、行距稳，是全站最「贵」的东西。

## 4. 明暗系统诊断

### 现状

- **首页：** 深色首屏（蓝黑 + 3D 图）→ 白（数据条、资质）→ 白（四类场景）→ 雾白 `#F6FAFC`（案例）→ **纯黑 `#000`**（四个工程问题）→ 白（合作模式）→ 白（团队）→ 雾白（洞察）→ 深蓝渐变（收尾）→ 纯黑（页脚）。
- **内页：** 全部是白色首屏（面包屑 + H1 + 右侧插画）→ 白 / 雾白交替 → 可选一段纯黑全宽区（technology、about）→ 白 / 雾白里嵌 1–2 块圆角黑卡 → 深蓝收尾 → 黑页脚。
- **过渡方式：** 全部是 0px 硬切。白与雾白之间加一条发丝线。唯一的「过渡」是首屏底部那圈青 / 琥珀辉光。

### 有规律的部分

- 首页深，内页浅。
- 白 / 雾白隔段交替。
- 每页以同一个深色 CTA + 黑页脚结尾。

### 问题

1. **深色有四种黑，角色没有定义。** 首屏蓝黑、内容区纯黑、内嵌卡 `#030B12` 或 `#000`、收尾渐变。哪一种是「品牌的夜色」没有答案。
2. **纯黑全宽段出现位置随意。** 首页在第 6–8 屏，about 是一条 440px 的横幅，technology 是 2.5 屏，case 页没有。它不承担固定的叙事角色。
3. **黑白硬切反差太大。** 21:1 的对比度从 `#000` 切到 `#FFF`，滚动时有「闪」的感觉，没有缓冲（半屏渐变、圆角收口或中间调都没有）。
4. **白与雾白差异过小，等于连续 4–5 屏同一种白。** 节奏靠段距硬撑，所以显得空。
5. **内嵌黑卡数量多且各不相同。** `en-case-proposal-d-02` 纯黑，`d-07` 是 `#000→#0D1D38` 渐变，`en-solution-doc-d-03` 带图，`en-technology-d-06` 纯黑 + 青按钮。在白页里像一个个黑洞。
6. **页头在首屏是一条灰带**（待核实，见第 17 条）。**〔更正〕已核实为真实问题，「待核实」作废。**

## 5. 把质感提升两个档次：表面与材质规范

### 底色层级

- **深色（夜色，带一点青蓝色相，禁用 `#000`）：**
  - N0 `#05090D` 页面底
  - N1 `#0A1117` 分区
  - N2 `#101A22` 卡片
  - N3 `#17242E` 浮层 / 悬停
- **浅色（纸，极轻的冷灰，禁用大面积纯 `#FFF`）：**
  - P0 `#F4F6F7` 页面底
  - P1 `#FAFBFB` 分区
  - P2 `#FFFFFF` 只给卡片和输入框——让「白」成为被抬起来的表面
  - P3 `#E9EEF0` 凹槽 / 表头
- **明暗之间：** 加一段 120–160px 的过渡带（N0→N1 的渐变收口，或让深色段以 32px 大圆角的整块「面板」嵌在浅色页里）。全站统一一种做法。

### 层次与高度

- 只设三档：平铺（无阴影）、抬起（卡片）、悬浮（菜单 / 截图）。
- **浅色卡：** P2 底 + `1px rgba(10,20,30,.08)` 描边 + 双层阴影 `0 1px 2px rgba(10,20,30,.06), 0 8px 24px -12px rgba(10,20,30,.10)`。
- **深色卡：** N2 底 + `1px rgba(255,255,255,.08)` 描边 + 顶部 1px 内高光 `inset 0 1px 0 rgba(255,255,255,.06)`。深色不要外阴影。
- 删掉截图卡底下那团大虚影。

### 描边

- 分隔线与卡片描边分开：
  - 分隔线：浅色 6% 黑，深色 8% 白。
  - 卡片描边：8–10%。
  - 强调描边：青 30%，只用于「当前选中」。
- 表格和并列格只用横线，不用竖线。

### 圆角

- 三档：8（控件）/ 14（卡片）/ 24（大面板、截图框）。
- 嵌套时内圆角 = 外圆角 − 内边距。
- 胶囊只留给按钮和标签。

### 光与渐变

- 渐变只用在三处：
  1. 深色段顶部一束很弱的青色径向光（直径约 800px，青 8–10% 透明度）；
  2. 图表线下的面积渐隐；
  3. 截图 / 图片底部向底色的渐隐。
- **禁止渐变按钮。** 主按钮改为：
  - 深色底上：实心 `#E8FBFE`（近白的青）配深色字；
  - 浅色底上：实心 N0 配白字；
  - 悬停时只加 1px 青描边发光。全站一套。

### 毛玻璃

- 只用于吸顶页头和下拉菜单（深色 `rgba(5,9,13,.72)` + 16px 模糊 + 底部 1px 发丝线），以及首屏舞台框叠在 3D 图上的那一处。
- 内容卡片一律不用。

### 动态光谱 / 渐变

- 最多用在两处：首屏光纤的缓慢流光（8–12 秒循环，青 → 青白，不引入品红和橙），收尾 CTA 的同一素材。
- 线框彩虹波全站下线。

### 图像风格

- **深色场景：** 一种 3D——青 / 青白玻璃与光纤，纯深色背景，单一主光自左上，无彩色珠子、无彩虹色散。
- **浅色页：** 一种 2D——单色线稿 + 一个强调色的工程示意图（参照 `en-technology-d-01`），SVG 矢量，直接画在页面上，没有底板。
- **界面：** 真实截图只做局部特写，统一放进同一种设备框（N2 底、24px 圆角、无仿 macOS 圆点，左上角放等宽系统名）。
- **人物：** 真实照片冷灰处理，或不放。

### 色彩纪律

- 品牌色只有青一族（`#0B7A8C` / `#22D3EE` / 一档更浅）。
- 语义色只留两种：琥珀 = 人工复核 / 注意；玫红 = 风险 / 旧做法。
- 钴蓝、紫、靛、绿、粉、橙、黄全部退出装饰用途。图表多系列用青的明度阶梯 + 中性灰。

### 明确反对的做法

- 纯 `#000` 与纯 `#FFF` 大面积直接相接。
- 用 `mix-blend-mode: multiply` 代替抠图。
- 糖果渐变胶囊按钮。
- 彩虹 / 全息 / 品红色散图。
- 同一张插画在一页重复。
- 水彩 / 生成风格的人物。
- 仿 macOS 红黄绿圆点。
- 把整屏截图缩到不可读当装饰。
- 发丝线同时充当分隔、卡片和表格。
- 中文套等宽字体。
- 每个区块都加等宽大写眉题。
- 为了「留白」制造 500px 以上的无内容空场。
